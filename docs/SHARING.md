# Try Brando

The [Windows preview release](https://github.com/Giacomo98DaRe/Brando-From-LaTeX-to-Word/releases/tag/v0.1.0-preview.1)
contains the portable app, checksums and dependency source archives. Download
`Brando-0.1.0-win32-AMD64.zip`; the source archives are for developers and license compliance.
No GitHub account is needed for public downloads.

Extract the whole ZIP to a writable local folder and open `Brando/Brando.exe`.
Keep `_internal` next to the executable. Try `example-project`, then an Overleaf source ZIP.
The preview is unsigned. If Windows or an organization policy blocks it, verify the source
and checksum and ask your IT administrator; do not disable security protections.

To share in Google Chat, paste the release link and pin the message. Chat blocks executable
attachments, including executable files inside ZIPs; use the download link instead.
See [Google Chat attachment restrictions](https://support.google.com/chat/answer/7651457?hl=en).

## Useful feedback

- Can the app start after extraction on a Windows computer without development tools?
- Do project ZIP/folder import, main selection, comments off/on and cancellation work?
- In Word, do authors, section text, signed numbers, equations, tables, citations and figures
  agree with the source? Are comments beside the intended paragraph or in Source annotations?

Report the app version, Windows/Word versions, expected behavior and actual behavior through
[GitHub issues](https://github.com/Giacomo98DaRe/Brando-From-LaTeX-to-Word/issues).
For reproducible bugs, prefer a small original example. Conversion reports may contain local
paths and source text: review them before posting. Do not upload private manuscripts.
